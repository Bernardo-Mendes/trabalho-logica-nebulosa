# 🩺 Sistema de Triagem Hospitalar Inteligente

Este projeto é uma aplicação web interativa desenvolvida com **Streamlit** e **Scikit-Fuzzy**. Ele implementa um motor de inferência baseado em Lógica Nebulosa (Fuzzy Logic) para classificar o nível de urgência de pacientes a partir de seus sinais vitais corporais e nível de dor.

## 🎓 Contexto Acadêmico

Projeto desenvolvido para o curso de **Sistemas de Informação** da **Universidade Federal Fluminense (UFF)**.

* **Disciplina:** Lógica Nebulosa
* **Professor:** Patrick Moratori
* **Desenvolvedores:** Bernardo Mendes, Joao Victor Souza e Davi Santiago
